# 验收场景与预期行为

1. **仅说“启动小红书对标分析”**：第一条回复必须输出指定三项输入的启动引导；1–3个账号，链接或截图、用户业务、目标。不得自带任何具体行业假设。
2. **用户一次给两条链接和用户业务/目标**：不重复提问，立即核验并研究；无法访问时不瞎填数据，必要时给阶段报告。
3. **用户只给主页截图**：直接根据可见简介、粉丝、封面做五维“初步报告”；无有效互动数据不得写TOP10或涨粉曲线。
4. **用户给多个截图，分别是账号A/B**：保持归属，不串账号；所有数值可追溯截图编号。
5. **某个截图上“1.2万”模糊不清**：标记无法辨认，不用其他账号类似数字猜测。
6. **用户目标是“获客成交”**：最终行动聚焦信任构建、咨询意图、具体内容；绝不虚构成交额。
7. **用户目标是“判断值不值得模仿”**：基于用户业务和资源匹配度给出选择、边界和证据，不能单看粉丝规模。
8. **输入4个账号**：引导优先选择1–3个或者自动按前3个处理并说明，不进入漫无边际采集。
9. **用户只给账号名且同名**：搜索可验证主页；无法确认时询问主页链接/截图，而不是用可能同名的结果。
10. **仅能读取登录页**：若有截图则继续截图分析；若没有数据则诚实说明当前无法验证，不编造数字或声称已成功采集。
