## 功能概述

根据用户提供的产品、卖点、人群信息，输出 5-8 个匹配 8 种内容框架的优化标题，每个标题附带框架类型、字数、张力检查结果，并给出 Top 3 推荐。

### 核心能力

| 能力 | 说明 |
|------|------|
| 🎯 **框架匹配** | 8 种内容框架自动匹配，支持用户指定框架 |
| 📏 **字数控制** | 严格 ≤20 汉字，含标点 |
| 🚫 **无 emoji** | 标题不含表情符号，排版干净 |
| 🔍 **张力检查** | 每个标题标注 6 项张力指标命中情况 |
| 📊 **Top 3 推荐** | 基于话题特性给出最佳选择 |

## 八种内容框架

| 编号 | 框架 | 标题方向 |
|------|------|---------|
| F1 | **痛点共鸣型** | 指向具体痛点场景，用情绪词引发共鸣 |
| F2 | **测评对比型** | 暗示横向对比或评测结论，用数字/结果钩子 |
| F3 | **故事叙事型** | 用时间线或个人经历开头，制造代入感 |
| F4 | **干货教程型** | 用方法/步骤/指南类关键词，降低认知成本 |
| F5 | **清单盘点型** | 用数字+盘点类关键词，制造完整感 |
| F6 | **反常识纠错型** | 用"别再""误区"制造冲突和好奇心 |
| F7 | **沉浸场景型** | 用具体场景/时间/动作开头，营造画面感 |
| F8 | **情绪价值型** | 用情绪金句或治愈感关键词，降低攻击性 |
