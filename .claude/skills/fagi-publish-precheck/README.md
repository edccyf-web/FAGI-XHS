## 功能概述

本 Skill 专注于国内自媒体（抖音/小红书/微信视频号）**发布前的内容风险自审**，核心能力包括：

- **发布前审稿**：提交口播稿/文章/图文笔记/字幕/封面文字，逐平台输出结论（可发/改后可发/不建议发）
- **保意修复**：用户要求改稿时，给出可直接替换的修复文本，保住作者口吻和信息密度
- **限流/处罚复盘**：被限流/删除/处罚后，按四类归因复盘
- **个人规则沉淀**：行业敏感词、误报白名单、踩坑案例自动沉淀，越用越准

```

           ▼

           │
           ▼

           ▼

│ Step 4：保意修复（用户要求改稿时）    │

           ▼
```

## 触发关键词

用户在对话中提到以下关键词时，会自动调用本 Skill：

- 能不能发、审一下稿子、查违禁词、查敏感词
- 会不会限流、被限流了、帮我改成能发的版本
- 发布前检查、被平台处罚、被删除了
- 帮我盯着这个词、导入违禁词表

## 核心能力

| 能力 | 说明 |
|------|------|
| 🔍 **发布前审稿** | 逐平台判定，输出原文位置+规则依据+修改建议 |
| ✏️ **保意修复** | 最小改写原则，保留作者口吻和信息密度，改完复检 |
| 📋 **限流复盘** | 四类归因：可证实违规/披露问题/推荐质量/未知信号 |
| 🧠 **个人规则沉淀** | 黑名单/白名单/语义规则/安全表达库，越用越准 |
| 👤 **账号类型识别** | 个人号 vs 企业号，不同尺度判定 |
| 📁 **审核历史存档** | 每次报告自动保存，可追溯 |
