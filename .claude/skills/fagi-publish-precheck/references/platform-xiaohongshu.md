# 小红书平台审核

目标平台含小红书时，每次必读 [交易导流审核](xiaohongshu-transaction-diversion.md)，按已核实的正式细则和用户提供的触点判定。该文件包含官方来源、生效日期、五类违规、误报边界、修复及处罚对象。

- 个人号、企业号、商家、买手及其他用户都受导流规则约束；账号身份影响可用工具和处罚条款，不构成站外导流许可。
- 除正文外，对已提供的主页、评论、群聊、私信、直播及商品售后独立核查；缺失触点标为未检查，不能声称账号整体安全。
- 营销披露、商品行业限制、社区内容规范等另按相应官方规则核查。本文件仅补齐交易导流部分，不代表其他小红书规则已完整收录；其他引用资料若仍是占位，应主动核实官方依据，不能用占位文档支持必改结论。
