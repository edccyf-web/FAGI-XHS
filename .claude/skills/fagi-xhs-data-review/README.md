# 小红书笔记数据复盘 Skill (xhs-data-review)

> 按漏斗逻辑诊断小红书笔记数据，定位问题层、归因、给出下一条动作，并识别内容加码/砍掉方向。

## 核心诊断漏斗

```
曝光量 → 点击率(CTR) → 互动(点赞/评论/收藏) → 涨粉
  L1          L2              L3                L4
```

## 安装方式

```bash
mkdir -p ~/.trae/skills/xhs-data-review
# 将本目录内容复制到该目录
```

## 触发关键词

数据复盘、笔记数据、诊断数据、小红书数据、复盘笔记、曝光低、点击率低、互动差、不涨粉

## 使用流程

1. 用户粘贴/上传笔记后台数据（曝光、点击率、互动、涨粉等）
2. 自动按漏斗层层定位问题（L1→L2→L3→L4）
3. 输出归因 + 下一条笔记的 1-2 个具体动作
4. 如有多条笔记，识别加码/砍掉规律
5. 输出可视化数据仪表盘
