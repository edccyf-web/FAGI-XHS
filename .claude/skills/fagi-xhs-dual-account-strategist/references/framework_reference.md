# 双账号内容策略框架参考

> 本文件为本 Skill 所引用的「双账号内容策略框架」参考说明。完整数据见生成的 xlsx 文件。

## 框架层级总览

本 Skill 使用了以下 6 层策略结构——每一层在 SKILL.md 中有对应的生成模块：

### Layer 1：策略总览
- 双账号定位区分：个人IP号 = 建信任、建黏性 / 品牌号 = 留资、预约
- 核心任务、内容调性、信任来源、读者感受、转化路径、CTA策略
- 模块对应：SKILL.md → 模块 A

### Layer 2：内容类型体系
- 个人IP号：5 种类型（行业洞察 30% / 设计哲学 20% / 主理人故事 20% / 客户手记 15% / 日常纪录 15%）
- 品牌号：5 种类型（方案展示 25% / 改造案例 22% / 痛点场景 22% / 干货知识 17% / 转化内容 14%）
- 模块对应：SKILL.md → 模块 B

### Layer 3：三阶段节奏
- M1 亮相期 → M2 深耕期 → M3 影响期
- 模块对应：SKILL.md → 模块 C

### Layer 4：月度选题表
- 每号 12 条/月（总计 24 条/月），每条 7 个字段
- 模块对应：SKILL.md → 模块 D

### Layer 5：双号联动机制
- 内容联动 + 评论引导 + 核心理念统一
- 模块对应：SKILL.md → 模块 E

### Layer 6：CTA 策略
- 个人号弱 CTA vs 品牌号强 CTA，按阶段升级
- 模块对应：SKILL.md → 模块 F

## 跨月记忆的编码方式

本 Skill 的「记忆」并非持久化存储，而是通过以下方式实现：

1. **对话时用户提交上月选题** → Skill 读取并分析
2. **阶段标记** → 用户在开场时告知是第几个月
3. **系列延续** → 从上次的干货①→干货②，案例→追踪
4. **下月预告** → 本月最后一条预设下月方向，下月读取呼应
