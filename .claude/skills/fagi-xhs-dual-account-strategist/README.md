## 功能概述

通过 **3 轮对话** 收集行业、品类、痛点三维度信息以及上月选题数据，生成可直接执行的双账号（个人IP号 + 品牌号）月度内容策略与 24 条选题规划，并自动实现跨月呼应与迭代优化。

本 Skill 的核心框架来自 **小红书双账号内容策略框架**，这是一个从实际案例中提取的 6 层可复用策略结构。

---

## 核心能力

| 能力 | 说明 |
|------|------|
| 🧠 **跨月记忆机制** | 自动识别上月选题，阶段递进、类型优化、系列延续、CTA 升级 |
| 👥 **双账号策略架构** | 个人IP号（建信任）+ 品牌号（留资），6 层策略体系 |
| 📅 **月度选题规划** | 每号 12 条/月 = 24 条/月，含标题、内容核心、视觉方向、CTA |
| 🔄 **系列内容延续** | 自动从「干货①」延续到「干货②③」，案例追踪等 |
| 🎯 **三维度输入** | 行业 + 品类 + 痛点，精准定位策略方向 |
| ✅ **质量审查清单** | 10 项发布前必查标准 |

## 核心差异点

与普通内容策划工具不同，本 Skill 的核心差异在于 **跨月记忆机制**：

| 特性 | 本 Skill | 普通工具 |
|------|---------|---------|
| 是否记住上月选题 | ✅ 自动分析上月数据进行延展 | ❌ 每次从头开始 |
| 阶段递进 | ✅ M1→M2→M3→循环迭代 | ❌ 每月独立，无连续性 |
| 系列内容延续 | ✅ 「干货①→②→③」自动延续 | ❌ 需手动创建系列 |
| CTA 升级 | ✅ 按阶段自动增强 | ❌ 固定不变 |
| 下月预告 | ✅ 本月末埋线索，下月呼应 | ❌ 无 |

## 工作原理

### 3 轮对话协议

| 轮次 | 目标 | 关键问题 |
|------|------|---------|
| 第 1 轮 | 行业认知 + 上月复盘 | 行业/品类/痛点关键词 + 第几个月 + 上月数据 |
| 第 2 轮 | 三维度挖掘 | 人群画像、账号现状、痛点细化、对标分析 |
| 第 3 轮 | 策略生成 | 确认信息 → 输出 6 模块策略 + 选题表 |

### 6 模块策略引擎

| 模块 | 内容 | 跨月影响 |
|------|------|---------|
| A 策略总览 | 双账号定位/调性/转化路径 | 首次生成 |
| B 内容类型 | 5 种类型 × 2 号 + 占比 | 上月数据优化占比 |
| C 三阶段节奏 | M1→M2→M3 | 自动递进 |
| D 月度选题表 | 24 条/月 | 系列延续 + 类型优化 |
| E 双号联动 | 内容联动 + 评论引导 | 每月固定 |
| F CTA 策略 | 按阶段升级 | M1 弱 → M3 强 |

### 跨月记忆机制

跨月记忆通过对话协议实现，无需持久化存储：

1. 用户第 N 次调用时提交上月选题规划
2. Skill 读取后自动分析：阶段位置、类型分布、可延续系列、可优化点
3. 自动递进阶段（M1→M2→M3→循环），延续系列内容
4. 本月最后一条内置「下月预告」，下月生成时读取呼应
