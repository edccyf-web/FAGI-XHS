# xhs-keyword-planner

**小红书关键词规划工具 · Xiaohongshu Keyword Planner v1.1.0**

> 10 维关键词矩阵 + 搜索量验证 + 账号阶段部署。输出 Excel + Markdown 双格式关键词矩阵，含搜索意图、搜索量、策略评级、账号分配建议和分阶段部署策略。

## 核心能力

| 能力 | 说明 |
|------|------|
| 🔍 **搜索量验证** | 内置必做步骤，DSO100 词根验证 + T1/T2/T3 置信度分级 |
| 📊 **双格式输出** | Excel (.xlsx 含 3 个 Sheet) + Markdown 结构化报告 |
| 👤 **账号阶段策略** | 新号起号期/成长期/成熟期三种部署方案，含执行日历 |
| 🏷️ **10 维矩阵** | 品牌/场景/痛点/方案/本地/风格/竞品拦截/长尾/属性/决策指南 |
| ⭐ **策略评级** | ★★★★★ 五星体系，结合搜索量数据校准 |

## v1.0 → v1.1 更新
